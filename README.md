# 子供のMac 通知エージェント（Mac版）

ゲーム中に「静かにして」／お風呂などの定時リマインドを、
子供のMacの画面中央に大きく表示＋音声読み上げする仕組みです。

仕組み: 送信側（Muse / 親のスマホ）→ ntfy.sh（無料の通知中継）→ 子供のMacの常駐プログラム → ダイアログ表示

## セットアップ（子供のMacで1回だけ、約3分）

1. このフォルダを子供のMacにコピー（AirDrop / USB / iCloud Drive どれでもOK）
2. 「ターミナル」アプリを開いて、このフォルダの中で次を実行:
   ```
   chmod +x install.sh uninstall.sh
   ./install.sh
   ```
   ※ 最初に Python のインストール案内が出たら「インストール」を押してください（macOS標準の案内です）
3. 画面に表示される「送信先トピック（自動生成された文字列）」を Muse のチャットに送る
   → Muse がその宛先を覚えて、以後はこのチャットから送れるようになります
4. セットアップ直後にテスト通知が自動で1通届きます。ダイアログと音声が出たら成功です

## 使い方（セットアップ後）

- 即時通知: Muse のチャットで「子供に『声でかいよ、静かにして』って送って」等と言うだけ
- 通知のみ（画面を止めたくない時）: メッセージ先頭に NOTIFY: を付けると右上の通知だけ
- 定時リマインド: お風呂・就寝などの時刻を Muse に伝えると、毎日その時刻に自動送信するよう設定できます

## 補足

- 時間制限・アプリ制限は macOS 標準の「スクリーンタイム」（設定 → スクリーンタイム、ファミリー共有）が別途おすすめです。本エージェントは「声かけ専用」です
- フルスクリーンのゲーム中はダイアログが背面になる場合がありますが、通知と音声読み上げは届きます
- やめたい時: このフォルダで `./uninstall.sh` を実行すると完全に消えます
- トピック名は合言葉です。他人に知られると通知を送れてしまうので、SNS等に載せないでください
